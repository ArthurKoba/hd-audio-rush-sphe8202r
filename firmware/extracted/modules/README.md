# STK module set

This directory contains the 18 module slots exported from the canonical stock dump by Sunplus STK 0.2.3 rev 8203R.

The files are byte-exact evidence and must not be edited in place. Their source archive is `../modules.tar`; hashes are recorded in `../SHA256SUMS`.

Reverse annotations, patched binaries and Ghidra project state belong elsewhere.
