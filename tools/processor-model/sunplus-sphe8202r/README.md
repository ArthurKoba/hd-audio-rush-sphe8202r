# Sunplus SPHE8202R — исходная процессорная модель

Здесь хранится только редактируемая процессорная модель, независимо
от наличия репозитория ghidra-mcp.

- SunplusSPHEAudioDSP/ — исходники SLEIGH (.slaspec, .sinc),
  язык (.ldefs), процессор и ABI (.pspec, .cspec).
- java/com/xebyte/sunplus/ — Java-механизмы архитектуры и восстановления
  DO/CE, CALL/RTS, владельцев PM, DM16, переходов и состояний.
  Эти классы интегрируются в Ghidra MCP и зависят от его API.

Для установки поместить процессор в
Ghidra/Processors/SunplusSPHEAudioDSP, скомпилировать SLEIGH
средствами Ghidra 12.1.3; Java-классы собрать в проекте
интеграции с Ghidra 12.1.3/JDK 21.

Принятая внедрённая версия: `ghidra-mcp/main`, коммит
`07577ecbddd6c76acc3795622fc08ec2dc73044c` (PR #68, CI/CD и Coolify #1072).
Все 18 исходных файлов модели сверены по Git blob SHA с принятой версией
Ghidra MCP; повторное копирование исходников не требуется.
В репозитории RUSH намеренно нет JAR, скомпилированных .sla,
полных копий ghidra-mcp, тестовых отчётов, резервных копий и
патчей Ghidra. Они не являются исходниками процессорной модели.

Покрытие C/CE и поведение реального чипа оцениваются отдельно;
этот набор не означает полного аппаратного подтверждения.


Обновление локально принятой процессорной модели (27.10.2026):
нативные вложенные DO/CE и источник аппаратного CNTR, возвращающийся
CALL внутри циклов, строго доказанный constant-false IF EQ после
неvolatile DM read-back. Для интеграции Java-классов в Ghidra MCP
после сохранения обычного анализа подключить
SunplusNativeCallLoopClosureRecovery.applyAfterSavedAnalysis перед
обычным проходом SunplusNativeCeAutoAnalyzer, а восстановление
ложного условного перехода выполняет
SunplusNativeFalseBranchFlowRecovery.applyAfterSavedAnalysis.
**Каноническая приёмка Analyzer MCP, 27.10.2026:** четыре сохранённые
исходные программы PCM, AUX, DTS и AC-3; **565/565 нативных функций C**,
**536/536 прямых DO/CE**, **0 отказов C**, **0 предупреждений C**,
**0 нерешённых непрямых CE**. Для всех четырёх программ C-индексы привязаны
к проекту, сохранены, повторно открыты и сверены по SHA-256.
Границы: только C/CE в этом инвентаре. Семантика аудиоалгоритмов,
межмодульные зависимости, физическое выполнение и аппаратные эффекты
подтверждаются отдельно; полное покрытие этих областей не заявляется.
Исходные образы прошивки не изменялись.
