# UART evidence

`ac695n-boot-excerpt.log` is a curated excerpt copied from the user-supplied runtime capture. It preserves the firmware/build/audio anchors used in the initial reverse work, but is not represented as a complete byte-for-byte serial-session archive.

When a raw capture is saved directly from the serial terminal, add it as a separate immutable evidence artifact with timestamp/context and SHA-256 rather than replacing this excerpt.
